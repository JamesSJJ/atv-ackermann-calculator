Geometry inputs — edit measurements below

For accurate results, enter the actual steering-axis ground projection, not simply the upper ball-joint center. Steering arm offsets are measured from each steering pivot. Left/right X offsets use global coordinates (+ right). Each stem plate hole has independent X and Y offsets.

Calculated steering

Ackermann % = actual inside/outside wheel-angle difference ÷ ideal difference × 100. Undefined at straight ahead. Ideal is computed for the inside wheel angle using wheelbase and track. Positive steering is a left turn in this model.
